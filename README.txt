# Happy Dussehra Greeting Website

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.
3. No installation, framework, or internet connection is required.

## Included
- Responsive HTML/CSS layout
- Animated canvas fireworks
- Dussehra greeting cards
- Share greeting button (uses native share where supported; otherwise copies text)
- Theme toggle
- Optional synthesized chime controlled by the visitor

To customize the greeting, edit the message inside `index.html`.
